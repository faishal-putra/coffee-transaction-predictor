# Coffee Transaction Predictor

Sistem Prediksi Total Transaksi Kedai Kopi Menggunakan Machine Learning (Streamlit).

## Cara menjalankan (Windows PowerShell)

    python -m venv venv
    .\venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    streamlit run app.py

File `coffee_transaction_model.joblib` harus berada satu folder dengan `app.py`.
